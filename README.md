# TUSRUTASPERU — App de competencia viajera

La primera competencia viajera del Perú: 12 lugares de Huaral, un GPS,
un cronómetro y una sola meta: Rúpac.

- Sitio en vivo: https://tusrutasperu-app.netlify.app/
- Sin build: sitio estático, se publica directo desde `main`.
- Cada push a `main` redespliega automáticamente en Netlify (~1 min).
